نقشه‌ی راه سه provider دیگر دارد: ChatGPT و Claude.ai در خانواده‌ی web-chat (فقط selectorها و دو بررسی)، و providerهای API که به یک پیام اختیاری تازه برای نمایش جواب نیاز دارند. هر سه بدون تغییر اپ یا پروتکل اضافه می‌شوند، و آزمون واقعی معماری همین است.

THE TWO-MINUTE VERSION

CaptionRelay sends everything Windows Live Captions heard since the last send into a Gemini web chat with one hotkey, without moving focus. A C# tray app reads Live Captions through UI Automation every 120 ms and merges each rolling, self-correcting snapshot into one transcript with a word-alignment algorithm whose rule is "duplicate a few words, never lose one". A send is a ticket that is confirmed on success or restored on failure. A modifier-only hotkey is a pure state machine behind a low-level hook. The app talks to a Manifest V3 extension over a loopback WebSocket secured by Origin checks and a 256-bit token, with a small provider-neutral protocol. The extension delivers into the page with verified fallback chains, queues while the chat is answering, and survives hidden, throttled and frozen tabs. It is tested as a pyramid, from unit tests to replays of real recordings and measured live runs — about 80 ms from key to submitted message.
